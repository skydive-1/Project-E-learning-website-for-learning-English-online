 PHẦN 1: CHI TIẾT NHIỆM VỤ CỦA QUỐC ANH (FRONTEND & AI)
📌
 Hiện trạng:
Đã hoàn thành:
 Chặn F12/chuột phải, dừng video khi chuyển tab, thiết kế thành công ví Token AI thời gian thực. 
Mục tiêu tuần này:
 Kết nối hoàn chỉnh tính năng Quizzes sáng tạo (Writing & Pronunciation) với API chấm điểm thực tế bằng AI. 
🎯
 Các công việc cần làm và hướng dẫn chi tiết:
[TASK-FE-QUIZ-01] Ráp nối UI Quizzes sáng tạo (Writing & Pronunciation) với API thật 
Hướng dẫn thực hiện:
Kích hoạt giao diện gõ đoạn văn tự luận (Writing) và thu âm đọc câu (Pronunciation) đã dựng từ tuần trước. 
Khi học viên làm bài viết, thu thập chuỗi text; khi học viên làm bài phát âm, dùng Web Audio API xuất file ghi âm 
.mp3
 hoặc 
.wav
. 
Ráp nối, gọi API của Liêm để gửi dữ liệu bài làm lên hệ thống, sau đó hiển thị bảng đánh giá chi tiết (Điểm số, lỗi sai ngữ pháp, lỗi phát âm và câu sửa mẫu) do AI trả về trực quan trên giao diện. 
[TASK-FE-UAT-01] Kiểm thử trải nghiệm người dùng (UAT) trên các thiết bị
Hướng dẫn thực hiện:
 Phối hợp cùng Liêm kiểm tra lại toàn bộ luồng bảo mật video (chặn tải lậu, dừng video khi chuyển tab) trên các trình duyệt khác nhau (Chrome, Safari, Edge). Đảm bảo ví Token AI trừ mượt mà và hiển thị chính xác theo thời gian thực sau mỗi tin nhắn.

 PHẦN 2: CHI TIẾT NHIỆM VỤ CỦA LIÊM (BACKEND)
📌
 Hiện trạng:
Đã hoàn thành:
 Viết xong Signed URL bảo mật video, Middleware kiểm soát và đếm Token AI theo 3 Role. 
Mục tiêu tuần này:
 Phối hợp cùng Chương đồng bộ database thật, viết API chấm điểm Quizzes sáng tạo bằng AI. 
🛠
️ Các công việc cần làm và hướng dẫn chi tiết:
[TASK-BE-QUIZ-01] Viết API nhận diện âm thanh và chấm điểm tự luận bằng AI 
Hướng dẫn thực hiện:
Viết endpoint 
POST /api/quizzes/submit-writing
 để tiếp nhận bài luận của học viên. Thiết kế Prompt thông minh gửi sang Gemini API để chấm điểm và phát hiện lỗi ngữ pháp. 
Viết endpoint 
POST /api/quizzes/submit-audio
 tiếp nhận file ghi âm. Sử dụng Gemini SDK để nhận diện giọng nói từ file audio, đối chiếu với câu mẫu ban đầu để chấm điểm phát âm và trả về nhận xét chi tiết. 
[TASK-BE-DB-01] Thay thế bảng tạm Token sang bảng DB chính thức 
Hướng dẫn thực hiện:
 Sau khi Chương tạo xong bảng 
user_token_limits
 chính thức trên Supabase, Liêm thực hiện bóc tách toàn bộ mã nguồn đang sử dụng bảng tạm 
user_token_usage
 cũ và chuyển sang truy vấn, cập nhật trực tiếp trên bảng chính thức này.

️ PHẦN 3: CHI TIẾT NHIỆM VỤ CỦA CHƯƠNG (DATABASE) - 
🚨
 NHIỆM VỤ KHẨN CẤP
📌
 Hiện trạng:
Chưa hoàn thành tuần 6:
 Chưa tạo bảng hạn mức Token chính thức và chưa cập nhật bảng Questions phục vụ Quizzes sáng tạo. 
Mục tiêu tuần này:
 Giải quyết triệt để nợ kỹ thuật Database, đồng bộ hóa hệ thống dữ liệu thô về Docker. 
🎯
 Các công việc cần làm và hướng dẫn chi tiết:
[TASK-DB-AI-01] Khởi tạo bảng 
user_token_limits
 và Trigger tự động reset 
Hướng dẫn thực hiện:
Chạy câu lệnh tạo bảng chính thức 
user_token_limits
 trên Supabase bao gồm các trường: 
id
 (PK), 
user_id
 (FK), 
role
 (VARCHAR), 
tokens_used
 (INT), 
max_limit
 (INT), và 
last_reset_date
 (TIMESTAMP). 
Thiết lập một Trigger hoặc kích hoạt dịch vụ Cron Job (pg_cron) trên Supabase để tự động đặt giá trị 
tokens_used
 về lại 
0
 vào lúc 00:00 mỗi ngày. 
[TASK-DB-QUIZ-01] Tái cấu trúc bảng 
questions
 trên Supabase 
Hướng dẫn thực hiện:
Thực thi mã SQL: 
ALTER TABLE questions ADD COLUMN question_type VARCHAR(50) DEFAULT 'multiple_choice';
 để phân loại câu hỏi (Trắc nghiệm, Viết, Phát âm). 
Thực thi mã SQL thay đổi kiểu dữ liệu cột câu trả lời: 
ALTER TABLE questions ALTER COLUMN correct_answer TYPE TEXT;
 để lưu trữ thoải mái các đoạn prompt mẫu, bài viết mẫu của câu hỏi tự luận thay vì bị giới hạn 50 ký tự như cũ. 
Tiến hành chèn thêm dữ liệu mẫu (Seed data) cho ít nhất 5 câu hỏi tự luận và phát âm vào database. 
[TASK-DB-DOC-01] Đồng bộ hóa dữ liệu từ Supabase về Docker cục bộ 
Hướng dẫn thực hiện:
 Chỉnh sửa lại tệp script 
migrate_supabase_to_docker.js
. Đảm bảo tệp này quét và kéo đầy đủ cấu trúc bảng mới tạo (
user_token_limits
) cũng như schema cột mới của 
questions
 từ Supabase về container Docker cục bộ của nhóm. Chạy thử nghiệm đồng bộ để chắc chắn môi trường của 3 thành viên khớp nhau hoàn toàn.
